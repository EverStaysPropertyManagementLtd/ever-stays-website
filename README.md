# Ever Stays V27 — GitHub Pages

Repository name: `ever-stays-website`

## Publish
1. Create a **public** GitHub repository named `ever-stays-website`.
2. Upload the **contents of this folder** into the repository root (not a nested folder).
3. Under Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Configure the DNS `www` CNAME record to point to `<your-github-username>.github.io`. Do not literally use the placeholder. Set your custom domain in Pages to `www.everstays.co.uk` and enable Enforce HTTPS once available. Verify existing DNS records before editing.

## Before accepting live enquiries
- The form currently opens an email draft. It is **not** a server-side submission form. Connect and test a secure form provider before launching advertising.
- Set GA4 and Google Ads IDs in `consent.js` after validating cookie consent on the deployed site.
- Review legal policies and supplier disclosures.
- Confirm rights to the remote Manchester hero image and other imagery.
- Verify VAT treatment, pricing/photography terms, and site performance on mobile.
